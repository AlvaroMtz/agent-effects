Planned in **0.0.4**. Test toolkit for the effect boundary: a test runtime
with `when(...).respond(...)` stubs and assertions like
`toHaveRequestedEffect`, integrating with Vitest/Jest/Node test instead of
inventing a new runner. Agents become testable without internet, API keys,
or a database.
